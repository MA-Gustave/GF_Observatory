# GF Observatory — ADR-0006 — Versioned Profiles and Schemas

| Champ | Valeur |
|---|---|
| Document role | Compatibility decision |
| Decision status | Accepted |
| Implementation status | Not implemented |
| Verification status | Documentation structurally validated; implementation tests pending |
| Owner | GF Observatory maintainers |
| Last reviewed | 2026-07-24 |

## Décision

Plans, profils, signaux, schémas, statuts et analyseurs possèdent des identités et versions explicites permettant l’alignement par contrats.

## Conséquences

- le contrat est testable ;
- l’état d’implémentation reste séparé de la décision ;
- toute exception exige une nouvelle ADR.
