# GF Observatory — ADR-0008 — Retain Audit Evidence

## Décision

Observatory conserve une copie adressée par contenu des preuves structurées minimales nécessaires à l’audit historique.

## Conséquences

- le contrat est testable ;
- l’état d’implémentation reste séparé de la décision ;
- toute exception exige une nouvelle ADR.
